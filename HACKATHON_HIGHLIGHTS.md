# 🎃 Kiroween Hackathon - Key Highlights

## 👻 Project Name: **Kiro's Ghost** (The Phantom IDE)

### 🎭 The Concept
A possessed web application that channels Kiro AI's power without requiring IDE installation - bringing AI-powered development to any device, anywhere.

## 🚀 Technical Stack

### Frontend
- React 19 + TypeScript 5.9
- Vite 7 (blazing fast)
- Tailwind CSS 4 (responsive design)
- Monaco Editor (in-browser code editing)
- Framer Motion (smooth animations)

### Backend
- Python 3.11+ + FastAPI
- Uvicorn (ASGI server)
- Pydantic (data validation)
- Direct kiro-cli integration

### Architecture
```
Browser (Any Device)
    ↓
React Frontend (Responsive)
    ↓
FastAPI Backend (RESTful)
    ↓
kiro-cli (AI Integration)
    ↓
Kiro AI (Code Generation)
```
