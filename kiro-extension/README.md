## 🚀 Quick Start

### 1. Install
The extension is already installed!

### 2. Activate Theme
```
Ctrl+Shift+P → "Color Theme" → "🎃 Halloween Dark 👻"
```

### 3. Activate Icons
```
Ctrl+Shift+P → "File Icon Theme" → "🎃 Halloween Icons ⚰️"
```

### 4. Enable Effects
```
Ctrl+Shift+P → "🎃 Halloween: Enable Haunted Effects"
```

### 5. Enjoy! 🎃
- Move your mouse to see trails
- Click anywhere for explosions
- Click on ghosts to scare them!

## ⚙️ Settings

Configure in Settings (`Ctrl+,`) → Search "Halloween":

```json
{
  "halloween.effects.enabled": true,
  "halloween.effects.intensity": "high",
  "halloween.effects.ghosts": true,
  "halloween.effects.spiderWebs": true,
  "halloween.effects.particles": true,
  "halloween.effects.pumpkins": true,
  "halloween.effects.fog": true,
  "halloween.effects.mouseTrail": true,
  "halloween.effects.clickExplosions": true
}
```
