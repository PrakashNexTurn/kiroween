# ⌨️ Keyboard Shortcuts - Kiro's Ghost

Quick reference for all keyboard shortcuts in Kiro's Ghost.

## Global Shortcuts

| Shortcut | Action | Context |
|----------|--------|---------|
| `Ctrl+K` / `Cmd+K` | Open adhoc task modal | Anywhere in project |
| `Escape` | Close modal/dialog | Any modal or dialog |

## Adhoc Task Modal

| Shortcut | Action |

## Tips

### Windows/Linux Users
- `Ctrl` is your primary modifier key
- Most shortcuts use `Ctrl` + letter

### Mac Users
- `Cmd` (⌘) is your primary modifier key
- `Option` (⌥) is used for some shortcuts
- Most shortcuts use `Cmd` + letter

### Universal Tips
- `Escape` closes most modals and dialogs
- `Tab` navigates between form fields
- `Enter` confirms actions in modals
- Arrow keys navigate lists and trees

## Customization

Currently, keyboard shortcuts are not customizable. If you need different shortcuts, please open an issue on the project repository.

## Accessibility

All keyboard shortcuts are designed to work with screen readers and assistive technologies. Focus indicators are visible for all interactive elements.

## Browser Conflicts

Some shortcuts may conflict with browser shortcuts:
- `Ctrl+T` / `Cmd+T` - New tab (browser)
- `Ctrl+W` / `Cmd+W` - Close tab (browser)
- `Ctrl+N` / `Cmd+N` - New window (browser)
- `Ctrl+R` / `Cmd+R` - Reload page (browser)

These browser shortcuts take precedence and cannot be overridden.

## Platform-Specific Notes

### Windows
- Uses `Ctrl` as primary modifier
- `Alt` for secondary actions
- `Shift` for extending selections

### macOS
- Uses `Cmd` (⌘) as primary modifier
- `Option` (⌥) for secondary actions
- `Shift` for extending selections

### Linux
- Uses `Ctrl` as primary modifier
- `Alt` for secondary actions
- `Shift` for extending selections
