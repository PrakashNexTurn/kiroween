# 🎃 Kiro's Ghost - Quick Start Guide

> Get haunted in 5 minutes! 👻

## What is Kiro's Ghost?

A complete Halloween-themed development ecosystem with:
- **Web Orchestrator**: AI-powered project management (works on mobile!)
- **VS Code Extension**: Spooky themes, icons, and effects
- **kiro-cli Integration**: Direct AI access without API keys

---

## 🚀 Quick Start

### Option 1: Web Orchestrator (Recommended for First Time)

**Start in 3 commands:**

```bash
# Terminal 1 - Backend
cd backend
pip install -r requirements.txt
python main.py

# Terminal 2 - Frontend
cd frontend
npm install
npm run dev
```

**Access:**
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000
- API Docs: http://localhost:8000/docs

**What you can do:**
- ✅ Create projects from any device (mobile, tablet, desktop)
- ✅ Generate AI-powered specs (requirements, design, tasks)
- ✅ Execute tasks with real-time progress
- ✅ Browse files with syntax highlighting
- ✅ Edit specs in Monaco editor
- ✅ Run adhoc tasks (Ctrl+K)

---

### Option 2: VS Code Extension (For Desktop Users)

**Install:**
1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Install from `kiro-extension/` folder
4. Or: `cd kiro-extension && vsce package` then install .vsix

**Activate:**
```
Ctrl+Shift+P → "Color Theme" → "🎃 Halloween Dark 👻"
Ctrl+Shift+P → "File Icon Theme" → "🎃 Halloween Icons ⚰️"
Ctrl+Shift+P → "🎃 Halloween: Enable Haunted Effects"
```

**What you get:**
- ✅ Halloween dark & light themes
- ✅ Spooky file icons (coffins, pumpkins, ghosts)
- ✅ Interactive effects (floating ghosts, mouse trails, click explosions)
- ✅ Customizable settings
